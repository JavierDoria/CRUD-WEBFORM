# CRUD Web con ASP.NET Web Forms 

## Descripción
Desarrollo de una aplicación web utilizando ASP.NET Web Forms, estructurada en arquitectura en capas (EntityLayer, DataLayer, BusinessLayer y PresentationLayer).
Implementación de operaciones CRUD para gestión de datos persistidos en SQL Server.

Sistema donde se podra registrara un nuevo empleado, la cual tendra como campos, Nombre, Departamento, Sueldo y Fecha De Contrato. Tambien se podra editar y eliminar.

## Tecnologías utilizadas
- ASP.NET Web Forms - CRUD
- C#
- SQL Server
- jQuery/DataTables
- HTML5, CSS3
- Bootstrap
